# OreLens — MVP Scope

## Build now

### Backend

- Set up the project.
- Create clients for Sectors, World Bank, FRED, UN Comtrade, and EIA.
- Add raw-data storage or cache.
- Define a common normalized data schema.
- Fetch sample data for Coal, Gold, Nickel, and Copper.

### Frontend

Build the agreed views with mock data while the actual data audit is running:

- Commodity Overview
- Commodity Driver Map
- Company Comparison
- Company Detail
- Exposure/Resilience breakdown
- Evidence View
- Scenario UI

## Pending before final scoring

- Actual API availability audit.
- Correlation screening.
- Regression.
- Rolling analysis.
- Regime comparison.
- Historical weighting.
- Backtest.

## Explicitly deferred

- Final scoring weights.
- Final decision logic.

These must not be hard-coded before actual historical data has been collected and evaluated.
